# Installing Chris's AIOS: two pastes

You need the ChatGPT app on your Mac with Codex signed in. No GitHub account needed.

## Paste 1: put it on your Mac

In the ChatGPT app, open **Codex**, start a new task with your **home folder** as the folder, and paste:

```
Clone https://github.com/jbellsolutions/chris-aios into ~/chris-aios. If ~/chris-aios already exists, don't overwrite it: run git pull inside it instead.
If Codex asks to allow network access for this, I'll click Allow.
If my Mac asks to install the Command Line Tools, tell me to click Install, wait for it to finish, then try again.
When ~/chris-aios/AGENTS.md exists, tell me: "Done. Now start a new Codex task in ~/chris-aios and say: set up my AIOS."
```

No Codex handy? Open https://github.com/jbellsolutions/chris-aios, click the green **Code** button, then **Download ZIP**. Double-click the zip in Downloads, rename the `chris-aios-main` folder to `chris-aios`, and drag it into your home folder. Same result.

## Paste 2: let it set itself up

In Codex, start a **new task with the folder `~/chris-aios`** (choose the folder when you start the task), and say:

```
Set up my AIOS.
```

It reads its instructions, asks you five questions one at a time, connects your apps with you, and shows you last night's EOD check. Nothing posts, sends, books or spends without your yes.

## After that

- Business: always start Codex tasks in `~/chris-aios`.
- Your personal side: `~/chris-life` (setup makes it).
- The peptide business: `~/chris-peptide` (setup makes it).
- **Updates:** when Justin improves it, say "pull the latest updates" in a Codex task in `~/chris-aios`. Your answers, memory and logs are never touched: they live in folders the updates skip.
